# FabriPix starter

A minimal Vite + React + TypeScript app with the [FabriPix](https://fabri-pix.vercel.app) image editor.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/vikhyatsingh123/fabri-pix/tree/main/starter?file=src%2FApp.tsx)

Run it locally:

```bash
npm install
npm run dev
```

Everything happens in [`src/App.tsx`](./src/App.tsx). The [documentation](https://fabri-pix.vercel.app/docs) shows
what to change next: [tools & menus](https://fabri-pix.vercel.app/docs/tools-and-menus),
[theme](https://fabri-pix.vercel.app/docs/theming), [saving](https://fabri-pix.vercel.app/docs/saving-and-exporting).
